# RHAIMERS

即興ライム入力とAIバース生成でラップバトルを楽しむUnity製PCゲームです。

## Development Environment

* Unity: 6000.3.15f1
* Template: Universal 2D
* Target Platform: PC
* Input Device: Keyboard / Mouse

## Project Structure
```
Assets/
├─ RhAImers/
│  ├─ Scripts/
│  ├─ Scenes/
│  ├─ Prefabs/
│  ├─ Sprites/
│  ├─ Audio/
│  └─ UI/
├─ Settings/
└─ TextMesh Pro/
```

## Notes
UnityプロジェクトのルートをGit管理しています。
Library/, Temp/, Obj/, Builds/, Logs/ などの自動生成ファイルはGit管理しません。
Unityのバージョンは ProjectSettings/ProjectVersion.txt で管理します。

## How to Open

1. Unity Hubを開く
2. `Add project from disk` を選択
3. このリポジトリのルートフォルダを指定
4. Unity `6000.3.15f1` で開く
